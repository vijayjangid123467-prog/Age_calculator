#📌 Project Title:

Age Calculator Using Python

#📖 Description

>This is a simple Python project that calculates a person's age based on their birth year and the current year entered by the user. The program takes input from the user, performs a >subtraction operation, and displays the calculated age.

#🚀 Features
>Takes birth year as input.
>Takes current year as input.
>Calculates the age automatically.
>Easy to understand for Python beginners.
#🛠️ Technologies Used
Python 3
#💻 Code
>Python
>birth_year = int(input("Enter birth year: "))
>current_year = int(input("Enter current year: "))
>age = current_year - birth_year
>print("Your age is", age)

#▶️ How to Run
>Install Python on your computer.
>Save the code in a file named age_calculator.py.
>Open a terminal or command prompt.
>Navigate to the file location.
>Run the program using:
>Shell
>python age_calculator.py
>📷 Example Output
>Plain Text
>Enter birth year: 2005
>Enter current year: 2026
>Your age is 21
